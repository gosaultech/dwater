# Fonts for the walls

Lettering for `tools/assets/decals.py` (sprayed words, marker tags, stencils) and the tram's
dot-matrix display. All come from the Google Fonts repository (github.com/google/fonts); each
directory keeps the font's own licence file beside it.

| Directory | Font | Licence | Used for |
|---|---|---|---|
| `sedgwickavedisplay`, `sedgwickave` | Sedgwick Ave (Display) | SIL OFL 1.1 | tags |
| `permanentmarker` | Permanent Marker | Apache 2.0 | marker scrawl |
| `rocksalt` | Rock Salt | Apache 2.0 | scratchy marker |
| `rubikspraypaint`, `rubikwetpaint` | Rubik Spray Paint, Rubik Wet Paint | SIL OFL 1.1 | fat-cap spray |
| `coveredbyyourgrace`, `reeniebeanie`, `nothingyoucoulddo` | handwriting | SIL OFL 1.1 | hurried messages |
| `sairastencilone`, `protestguerrilla` | stencil and protest lettering | SIL OFL 1.1 | rescue teams' stencils, slogans |
| `vt323` | VT323 | SIL OFL 1.1 | dot-matrix displays |

ELI5: a box of real pens. The old walls were lettered with one tidy office typeface, which is why
they looked typed; these are the marker, the spray can and the stencil.
