# Fonts

All three families are under the SIL Open Font License 1.1 (the `OFL-*.txt` beside them): free to
use, bundle and ship with the game, not to be sold on their own. Downloaded from Google Fonts.

| File | Family | Used for |
|---|---|---|
| `Cinzel-Regular.ttf`, `Cinzel-Bold.ttf` | Cinzel (The Cinzel Project Authors) | headings, tabs, item names, the action list |
| `EBGaramond-Regular.ttf`, `EBGaramond-SemiBold.ttf`, `EBGaramond-Italic.ttf` | EB Garamond (The EB Garamond Project Authors) | descriptions, notes, counts, button help |
| `IMFellEnglish-Regular.ttf` | IM FELL English (Igino Marini) | the death screen |
